# Hush-Hush

Hush-Hush is a software engineering company with 14 years in business and a team of 20-30 engineers.

We build and operate software across product development, backend systems, data engineering, cloud infrastructure, privacy, system integration, industrial software, and applied AI.

## Software & Product Engineering

We design and build new products, extend existing systems, and work with long-lived production codebases.

Our work includes:

- backend and API development
- web applications and internal tools
- distributed and asynchronous systems
- third-party integrations
- event-driven systems and message queues
- database design and performance
- modernization of existing applications
- CI/CD and development tooling

## Data Engineering

We build pipelines and platforms that collect, process, transform, validate, enrich, and deliver data from websites, APIs, databases, files, and external systems.

Our work includes:

- ETL and ELT pipelines
- large-scale web crawling and extraction
- batch and streaming processing
- normalization, enrichment, and deduplication
- data reconciliation and validation
- orchestration and background processing
- analytical and operational data stores
- large-volume cloud processing

Our projects have included multi-terabyte datasets and systems processing millions of documents and records.

## Data Privacy & Masking

We develop and maintain our own data masking product for working safely with sensitive data.

It covers:

- deterministic and consistent masking
- pseudonymization
- generalization and transformation
- referential integrity
- masked and synthetic test data
- database and file processing
- auditable transformations
- performance on large datasets

This also gives us direct product experience with privacy-sensitive software, long-term compatibility, deployment, customer data, and ongoing product development.
